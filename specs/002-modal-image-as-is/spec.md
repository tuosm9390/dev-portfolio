# Feature Specification: 프로젝트 모달 이미지 표시 방식 수정

**Feature Branch**: `002-modal-image-as-is`  
**Created**: 2026-03-23  
**Status**: Draft  
**Input**: User description: "프로젝트 내용표시 모달창에 이미지를 각 프로젝트의 썸네일이미지가 그대로 표시되도록 수정해줘."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 프로젝트 이미지 원본 비율 확인 (Priority: P1)

사용자가 프로젝트 카드를 클릭하여 상세 내용을 확인할 때, 모달 상단에 표시되는 이미지가 고정된 16:9 비율로 크롭되지 않고 프로젝트 본연의 썸네일 이미지 비율 그대로(as is) 선명하게 보여야 합니다.

**Why this priority**: 포트폴리오 웹사이트에서 프로젝트의 첫인상을 결정하는 것은 시각적 요소입니다. 이미지가 왜곡되거나 잘리면 프로젝트의 의도나 품질이 낮게 평가될 수 있으므로 가장 높은 우선순위를 가집니다.

**Independent Test**: 개별 프로젝트 모달을 열어 다양한 비율(가로형, 세로형 등)의 이미지가 잘림 없이 전체적으로 표시되는지 확인하여 테스트할 수 있습니다.

**Acceptance Scenarios**:

1. **Given** 프로젝트 상세 모달이 열린 상태, **When** 이미지가 로드될 때, **Then** 이미지가 16:9 비율로 강제 크롭되지 않고 원본 비율을 유지하며 전체가 표시된다.
2. **Given** 이미지가 세로로 긴 경우, **When** 모달에 표시될 때, **Then** 모달의 가로 너비에 맞춰 크기가 조정되되 전체 이미지가 노출되도록 레이아웃이 유연하게 대응한다.

---

### User Story 2 - 반응형 이미지 레이아웃 (Priority: P2)

모바일 기기나 작은 화면에서도 이미지가 화면 밖으로 나가지 않고, 장치 너비에 맞게 적절히 축소되면서 비율을 유지해야 합니다.

**Why this priority**: 다양한 디바이스 환경에서 일관된 사용자 경험을 제공하기 위해 필요합니다.

**Independent Test**: 브라우저 창 크기를 조절하거나 모바일 기기 시뮬레이터를 통해 이미지 크기가 유연하게 조정되는지 확인합니다.

**Acceptance Scenarios**:

1. **Given** 모바일 화면 환경에서, **When** 프로젝트 모달을 열 때, **Then** 이미지가 화면 너비를 초과하지 않고 비율을 유지하며 최적의 크기로 표시된다.

---

### Edge Cases

- **이미지 로드 실패**: 이미지를 불러올 수 없는 경우, 현재의 그라데이션 배경과 "Image not available" 메시지가 정상적으로 표시되어야 합니다.
- **매우 긴 세로 이미지**: 이미지가 극단적으로 길 경우, 모달창의 전체 높이를 초과하지 않도록 최대 높이 제한이 적용되어야 하며, 필요시 스크롤을 통해 확인할 수 있어야 합니다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 모달창의 헤더 영역 이미지를 `object-cover` 대신 원본 비율을 유지하는 방식으로 렌더링해야 한다.
- **FR-002**: 시스템은 `aspect-[16/9]`와 같은 고정 종횡비 제한을 제거하거나 유연하게 변경해야 한다.
- **FR-003**: 이미지는 부모 컨테이너의 너비(100%)에 맞춰 자동으로 크기가 조정되어야 한다.
- **FR-004**: 이미지 로딩 중이나 실패 시의 Fallback UI(그라데이션 등)는 기존 디자인 컨셉을 유지해야 한다.
- **FR-005**: 모달창 내부의 텍스트 콘텐츠는 이미지 크기 변화에 영향을 받지 않고 정상적으로 배치되어야 한다.

### Key Entities *(include if feature involves data)*

- **Project**: 프로젝트 정보를 담고 있는 개체 (id, title, imageUrl, accentColor 등 포함)

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 모든 프로젝트 모달에서 이미지가 크롭(잘림) 없이 전체 영역이 100% 표시됨.
- **SC-002**: 모바일 및 데스크톱 환경에서 이미지의 가로세로 비율이 원본과 동일하게 유지됨 (왜곡 발생률 0%).
- **SC-003**: 이미지 표시 방식 변경 후에도 모달창의 초기 렌더링 속도(LCP)가 저하되지 않음.
