# Quickstart: 프로젝트 모달 이미지 표시 개선

## 구현 개요
고정 비율의 이미지 영역을 가변적이고 원본 친화적인(as-is) 영역으로 전환함.

## 주요 변경 사항
- `src/components/ProjectModal.tsx`:
  - `aspect-[16/9]` 클래스 제거
  - `object-cover` 대신 `object-contain` 또는 `w-full h-auto` 조합 사용
  - 이미지 컨테이너에 `max-h-[70vh]` 등의 한계치 설정 (사용자 가독성 보장)

## 실행 방법
1. 로컬 개발 서버 실행: `npm run dev`
2. 브라우저에서 포트폴리오 프로젝트 섹션으로 이동
3. 다양한 프로젝트(가로, 세로형 등)의 카드를 클릭하여 모달창 열기
4. 이미지가 원본 비율을 유지하며 잘림 없이 표시되는지 확인

## 검증 체크리스트
- [ ] 이미지가 16:9 비율로 강제 크롭되지 않는가?
- [ ] 이미지가 모달의 너비를 초과하지 않는가?
- [ ] 이미지 로드 중 레이아웃이 급격히 튀지 않는가?
- [ ] 모바일 환경에서 이미지가 최적으로 축소되는가?
